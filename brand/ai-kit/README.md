# CAMPS.ES brand kit (обновлённая версия)

Стартовый набор сгенерирован [AI Brand Kit](https://baked.design/ai-brand-kit/) (Baked Design Studio) по живому сайту https://grimaldsociales-prog.github.io/campses/ и затем доработан вручную: исправлены шрифты, радиусы и правила цвета, добавлены логотипы и собственные макеты. Полный брендбук: `../index.html`.

| Файл | Для чего |
| --- | --- |
| `DESIGN.md` | Цвета, шрифты, компоненты (формат Google DESIGN.md) |
| `BRAND.md` | Миссия, голос, правила логотипа |
| `SKILL.md` | Всё в одном файле как Claude-skill |
| `../logo/` | Логотипы, иконки, фавикон, бейдж |

Как использовать: Claude — загрузить `SKILL.md` как skill; Claude Code — положить в `.claude/skills/camps-es-brand/`; Cursor/Codex/Copilot — держать `DESIGN.md` в корне проекта; ChatGPT — приложить `DESIGN.md` и `BRAND.md`.
